# CrispyPaper

Paperback **0.8** source repository by CrispyDepression. One link adds every source below.

## Install link

Paste this into Paperback (Settings → External Sources → Add Repository):

```
https://raw.githubusercontent.com/Crispy-Depression/CrispyPaper/main/CrispyDepression
```

## Sources

| Source | Site |
| --- | --- |
| Comick | comick.live / comick.art / comick.dev |
| MangaFire | mangafire.to |
| WeebCentral | weebcentral.com |

New sources are added to this same link, so you never have to add another repo.

## Notes

- All sources sit behind Cloudflare or a captcha. Open the source's homepage in Paperback and tap the cloud icon before reading. MangaFire may show a shape captcha there: solve it, then close the window.
- Quick check that the upload worked: open `https://raw.githubusercontent.com/Crispy-Depression/CrispyPaper/main/CrispyDepression/versioning.json` in Safari. It should show text starting with `{"buildTime"`.

## Updating

Delete the `CrispyDepression` folder from the repo, upload the new `CrispyDepression` folder, and commit. The link stays the same.
