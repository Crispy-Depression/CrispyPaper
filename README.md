# CrispyPaper

Extensions repository for Paperback 0.8 on iOS. Sources: Comick, MangaFire and WeebCentral.

To add it, open this on the iPhone that has Paperback and tap [link](https://crispy-depression.github.io/CrispyPaper/0.8/#add)

Or add it yourself under Settings > External Sources > Add Repository with this URL:

```
https://crispy-depression.github.io/CrispyPaper/0.8
```

All three sources sit behind Cloudflare, so open the source in Paperback and press the cloud icon before reading. MangaFire can also ask for a shape captcha there.
